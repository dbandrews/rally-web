# rally-web

This project is a migration of an old game I made and all assets to run on the web. 

I want to make a faithful recreation of the original game, but with a modern web stack and some improvements. The original game was written in C++ and used OpenGL for rendering. The new version uses Vite, TypeScript, and WebGL.

**Target: a full faithful port — the browser build should look identical to the original** (same handling,
same tracks and cars with their real meshes and liveries, same sounds, same look). All original assets are
ours and are in scope. Port status and roadmap: `PROGRESS.md`.
